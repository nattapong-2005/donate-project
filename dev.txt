ภาพรวมของระบบปัจจุบัน:
ระบบมีโครงสร้างพื้นฐานที่ดีมากแล้ว ทั้งระบบ Real-time Overlay บน OBS Studio, หน้าบริจาคพร้อม PromptPay,
ระบบตรวจสลิปผ่าน SlipOK, แผงควบคุมสไตล์ (Customizer) ที่ยืดหยุ่นสูง (ปรับฟอนต์, ขอบตัวอักษร, Spacing, สี, พรีวิวสด)
และระบบ TTS อ่านออกเสียงภาษาไทย

เพื่อให้ระบบก้าวสู่ระดับมืออาชีพ เทียบเท่าแพลตฟอร์มระดับสากล (เช่น Streamlabs, Tipme, StreamElements)
นี่คือฟีเจอร์และสิ่งที่ควรพัฒนาเพิ่มเติม โดยแบ่งตามหมวดหมู่ความสำคัญ:

--------------------------------------------------------------------------------
1. ด้านระบบแจ้งเตือนบน OBS (Alerts & Overlay Widgets)
--------------------------------------------------------------------------------
[x] 1.1 วิดเจ็ตหลอดเป้าหมายโดเนท (Donation Goal Bar)
    - เพิ่มหน้า Overlay ใหม่ เช่น `/overlay/goal` สำหรับแสดงหลอดความคืบหน้า
    - ตั้งเป้าหมายได้ เช่น "เป้าหมายซื้อการ์ดจอใหม่ 15,000 บาท"
    - อัปเดตหลอดความคืบหน้าแบบ Real-time ทันทีที่มีคนบริจาค
    
[x] 1.2 วิดเจ็ตแสดงชื่อผู้สนับสนุน (Recent / Top Donators Ticker)
    - เพิ่ม Overlay แถบวิ่ง หรือกล่องแสดง:
      - ผู้โดเนทล่าสุด (Recent Donator)
      - ผู้โดเนทสูงสุดประจำวัน/ประจำเดือน (Top Donator)
      - ผู้โดเนทสะสมสูงสุด (All-Time Leaderboard)

[ ] 1.3 ระบบ Alert ตามระดับยอดเงิน (Donation Amount Tiers)
    - กำหนดให้แสดง Effect / เสียง / รูปภาพ แตกต่างกันตามยอดโดเนท เช่น:
      - 10 - 99 บาท: อนิเมชั่นและเสียงแบบมาตรฐาน
      - 100 - 499 บาท: กรอบสีทอง มีไฟลุก และเสียงเชียร์
      - 500+ บาทขึ้นไป: เอฟเฟกต์อลังการ จอสะเทือน พร้อมเสียงเอฟเฟกต์พิเศษ

[ ] 1.4 รองรับการอัปโหลดรูปภาพ / GIF / วิดีโอใส (WebM) ประจำตัว
    - ให้สตรีมเมอร์อัปโหลดภาพ GIF ดุ๊กดิ๊ก หรือวิดีโอพื้นหลังโปร่งใส (Alpha WebM)
      มาแสดงคู่กับข้อความโดเนทแทนไอคอนแบบเดิม

--------------------------------------------------------------------------------
2. ด้านระบบเสียง & การอ่านออกเสียง (Audio & Text-to-Speech)
--------------------------------------------------------------------------------
[ ] 2.1 อัปเกรดเสียง TTS เป็น Cloud AI Voice
    - ปัจจุบันใช้ Web Speech API ของบราวเซอร์ ซึ่งเสียงอาจจะแข็งและขึ้นกับ OS ของเครื่องที่เปิด OBS
    - พัฒนาให้ต่อกับ Google Cloud Text-to-Speech หรือ ElevenLabs หรือ Azure Thai Voice
      เพื่อให้ได้เสียงภาษาไทยที่เป็นธรรมชาติ ไพเราะ และเหมือนคนจริงพูด

[ ] 2.2 อัปโหลดไฟล์เสียงแจ้งเตือนแบบกำหนดเอง (Custom Alert Sound MP3)
    - สตรีมเมอร์สามารถอัปโหลดไฟล์เสียง MP3/WAV ประจำช่องตนเองได้โดยตรง
    - ระบบพรีวิวฟังเสียงก่อนกดบันทึก

[ ] 2.3 ตัวกรองคำพูด TTS (TTS Word Replacement & Censor)
    - แปลงคำย่อ คำสแลง หรือคำด่า เช่น เปลี่ยนคำหยาบเป็นเสียงปี๊ป (Bleep)
    - ป้องกันการพิมพ์ตัวอักษรซ้ำๆ เพื่อป่วนเสียงพูด เช่น "กกกกกกกกกกกกกก"

--------------------------------------------------------------------------------
3. ด้านการควบคุมสดระหว่างสตรีม & การคัดกรอง (Live Moderation & Stream Deck)
--------------------------------------------------------------------------------
[ ] 3.1 ปุ่มควบคุมด่วนระหว่างสตรีม (Quick Action Controls)
    - สตรีมเมอร์สามารถเปิดหน้าควบคุมบนมือถือ หรือแท็บเล็ต เพื่อ:
      - ปุ่ม "ข้าม (Skip Alert)" เมื่อมีข้อความไม่เหมาะสมขึ้นจอ
      - ปุ่ม "เล่นซ้ำ (Replay Alert)" สำหรับข้อความที่สตรีมเมอร์พลาดไม่ได้ดู
      - ปุ่ม "ปิดเสียงชั่วคราว (Mute Alert)" เมื่ออยู่ในฉากสำคัญของเกมหรือติดเนื้อเรื่อง

[ ] 3.2 ระบบกักข้อความเพื่อตรวจสอบก่อนขึ้นจอ (Moderation Queue)
    - มีตัวเลือกเปิด "ตรวจก่อนขึ้นจอ (Manual Approval)"
    - ข้อความจะยังไม่ขึ้น OBS จนกว่าแอดมินหรือม็อดจะกดปุ่ม "อนุมัติ (Approve)"

[ ] 3.3 รองรับปุ่มลัด Elgato Stream Deck / Webhook API
    - สร้าง API Endpoint ให้สามารถผูกปุ่มลัดบน Stream Deck เพื่อกด Mute / Skip / Test Alert ได้ในคลิกเดียว

--------------------------------------------------------------------------------
4. ด้านระบบการชำระเงิน & การป้องกันทุจริต (Payment & Anti-Fraud)
--------------------------------------------------------------------------------
[ ] 4.1 ระบบป้องกันสลิปซ้ำขั้นสูง (Duplicate Slip Detection)
    - บันทึก `transRef` หรือรหัสอ้างอิงของสลิปธนาคารลงฐานข้อมูล
    - ปฏิเสธทันทีหากมีคนนำสลิปเดิมมาส่งซ้ำ เพื่อป้องกันการขโมยสลิปผู้อื่นมาแจ้งเตือนฟรี

[ ] 4.2 ตรวจสอบยอดเงินจริงตรงกับสลิป (Strict Amount Matching)
    - ตรวจสอบให้แน่ใจว่ายอดเงินในสลิปที่ SlipOK อ่านได้ ตรงกับยอดที่ผู้ใช้กรอกลงในฟอร์มแบบ 100%

[ ] 4.3 เพิ่มช่องทางการชำระเงินหลากหลาย
    - TrueMoney Wallet
    - บัตรเครดิต / เดบิต (ผ่าน Omise หรือ Stripe)
    - Rabbit LINE Pay

--------------------------------------------------------------------------------
5. ด้านประสบการณ์ผู้บริจาค & หน้าร้านโดเนท (Donor Experience & Gamification)
--------------------------------------------------------------------------------
[ ] 5.1 ระบบสติกเกอร์และอีโมจิดุ๊กดิ๊ก (Animated Stickers)
    - ผู้บริจาคสามารถเลือกส่งสติกเกอร์ดุ๊กดิ๊กขึ้นจอร่วมกับข้อความได้

[ ] 5.2 ระบบข้อความเน้นพิเศษ (Super / Highlighted Message)
    - ยอดเงินสูงสามารถเลือกสีพื้นหลังข้อความของตัวเอง หรือปักหมุดข้อความบนจอได้นานขึ้น

[ ] 5.3 หน้าประวัติและใบเสร็จของผู้บริจาค (Donor Profile)
    - ผู้ใช้สามารถล็อกอินเพื่อดูประวัติการสนับสนุนของตนเอง และสะสมแต้ม/เหรียญผู้สนับสนุน

--------------------------------------------------------------------------------
6. ด้านระบบหลังบ้าน & สถิติรายได้ (Analytics & Accounting)
--------------------------------------------------------------------------------
[x] 6.1 แดชบอร์ดสรุปสถิติเชิงลึก (Advanced Dashboard & Charts)
    - กราฟแสดงรายได้ รายวัน / รายสัปดาห์ / รายเดือน
    - ช่วงเวลาที่มีคนโดเนทมากที่สุด (Peak Hours)
    - รายชื่อ Top Donator ประจำเดือน


--------------------------------------------------------------------------------
7. ด้านสถาปัตยกรรม & ความเสถียร (Architecture, Performance & Security)
--------------------------------------------------------------------------------
[ ] 7.1 ระบบ Offline Queue & Auto-Reconnect สำหรับ OBS Studio
    - กรณีที่อินเทอร์เน็ตของสตรีมเมอร์กระตุก หรือหลุดชั่วขณะ หน้า Overlay จะ Reconnect อัตโนมัติ
      และดึงข้อความที่ตกค้างในฐานข้อมูลมาเล่นต่อให้ครบ ไม่สูญหาย

[ ] 7.2 ระบบจำกัดความถี่การยิง API (Rate Limiting)
    - ป้องกันการสแปมยิง API ที่ `/api/donate`, `/api/verify-slip`, `/api/admin/test-alert`
      ด้วย Upstash Redis หรือ In-Memory Rate Limiter

[ ] 7.3 นำเข้า/ส่งออกการตั้งค่าธีม (Theme Preset Import/Export JSON)
    - ให้สตรีมเมอร์สามารถกดดาวน์โหลดการตั้งค่าสี ฟอนต์ ขอบตัวอักษร เป็นไฟล์ `.json`
      เพื่อสำรองข้อมูล หรือแชร์ธีมสวยๆ ให้เพื่อนสตรีมเมอร์คนอื่นนำไปใช้ต่อได้ทันที
